# 麦哨快速上手

[返回中文首页](../README.md)

麦哨帮你控制电脑上的「按键说话」键。先确认目标软件能设置 PTT，再选择用手机摄像头还是电脑摄像头识别。

## 1. 安装

从 [GitHub Releases](https://github.com/klamo/VocaGate/releases) 下载实际发布的附件，并阅读该版本说明。`Source code.zip` 是源码，不是安装包。首次预览仅提供 Android 和 Windows；macOS 候选的 sidecar 检查失败，暂不提供下载。下列 Mac 步骤供后续包和本地构建参考。

| 设备 | 文件与步骤 |
| --- | --- |
| 安卓手机 | 下载 `.apk`，在文件管理器中打开，按系统提示允许该来源安装 |
| Apple Silicon Mac | 打开 `.dmg` 并复制 `VocaGate.app` 到「应用程序」；如果提供的是 `.zip`，先解压再复制 app |
| Windows x64 | 将 `.zip` 完整解压到普通可写目录，打开其中的 `VocaGate.exe`；不要只取出 exe，也不要在压缩包内直接启动 |

桌面预览包自带 Java、MediaPipe sidecar 和模型，无需安装 Java、Python 或 pip。开发用 `desktop.zip` 是另一种分发，不适用这里的说明。

### Android 升级

旧 debug 包与 release 包签名不同，不能直接覆盖。首次从 debug 切换时需卸载旧版，原设置和测试录音会被清除。已有同一 release 签名的版本，不要为了重装随意卸载；先阅读新版本的升级说明。

### 系统提示和权限

- macOS / Windows 预览版没有发行者签名；macOS 也没有 Apple 公证。出现首次打开提示时，核对下载来源和文件哈希，按系统提供的正常打开流程操作，不需要关闭系统安全保护。
- Mac 本机摄像头模式需要摄像头权限；按键控制需要「系统设置 → 隐私与安全性 → 辅助功能」权限。授权后可能需要退出并重新打开 app。
- 当前 Android 版本的启动流程要求摄像头和麦克风权限。音频辅助仍受视觉门控约束；权限可选化尚未完成。
- Windows 目标软件若以管理员身份运行，普通权限的麦哨可能无法向它发送按键。先用普通权限软件测试，再按需要匹配运行权限。

## 2. 选择识别方式

### 电脑摄像头

1. 电脑端选择「本机摄像头」。
2. 选择正确的摄像头，点击「查看摄像头」确认脸部与嘴部清楚可见。
3. 关闭预览窗口不会等同于停止识别；需要停用时点击主窗口「停止」。

<a id="phone"></a>

### 手机连接：先用手动 Wi-Fi 配对

手机和电脑必须在同一个可互通的局域网。访客网络、酒店或校园网可能禁止设备互联。Wi-Fi 模式不需要 USB 调试，也不需要先用 USB 授权。

**电脑端**

1. 输入来源选「手机 VocaGate」。
2. 连接方式选 `Wi-Fi` 或 `Auto`，点击「启动」。
3. 记下窗口显示的本机 IP、端口和六位配对码。

**手机端**

1. 打开麦哨，点击「显示设置」。
2. 在电脑连接里选择 `Wi-Fi` 或 `Auto`。
3. 填入电脑 IP、同一个端口（默认 `27183`）和配对码。
4. 保存，观察连接状态是否为 `PC: Wi-Fi connected`。

当前没有自动发现和扫码配对。若电脑端重启后配对码改变，需要重新填写。

<details>
<summary><strong>可选：USB 连接（需要开发者选项和系统 ADB）</strong></summary>

1. 手机开启「开发者选项 → USB 调试」，用数据线连接电脑。
2. 在手机系统弹窗中确认本次电脑的 USB 调试授权。
3. 电脑需要已有 Android Platform-Tools / ADB；当前安装包尚未内置 ADB。
4. 麦哨输入来源选「手机 VocaGate」，连接方式选 `USB` 或 `Auto`，点击「启动」。
5. 如果自动转发失败，可在终端检查：

```bash
adb devices
adb reverse tcp:27183 tcp:27183
adb reverse --list
```

手机端应显示 `PC: USB connected`。多设备连接时需指定设备序列号；当前桌面自动设置流程对多设备处理仍有限。部分 Windows 手机需要厂商 USB 驱动。

</details>

## 3. 设置按键并试说

1. 在麦哨选一个按键或组合键，例如 `CTRL+SHIFT+M`。
2. 在游戏 / 语音软件开启「按键说话」，设成完全相同的键。
3. 确认目标软件使用的是你想用的电脑麦克风或耳机麦克风。
4. 点击麦哨「启动」，说话时观察 `PRE_OPEN / OPEN`；停止后应回到阻断状态。
5. 遮挡摄像头、停止运行或断开手机，检查目标软件的按键是否释放。

`F13` 等键并非所有游戏都支持。确认基础链路正常后，再根据实际感受调参。

## 4. 怎么调得更顺手？

| 现象 | 先尝试 |
| --- | --- |
| 开头容易吞字 | 确认镜头能看清嘴部，再适当增加提前按键 / 首字保护 |
| 一句话被切成几段 | 适当增加闭麦保持，观察连续讲话时是否改善 |
| 不说话也容易开麦 | 降低灵敏度、首字保护或音频辅助档位，排查光照和遮挡 |
| 手机发热 | 使用黑屏保护，避免一边快充一边长时间满亮度预览 |

一次只改一项，保留前后对比。Android 的录音测试会生成时间线等长的 `full.wav` 和 `gated.wav`，可在「查看录音文件」中回放；开始新测试会替换上一轮记录。

音频辅助是当前源码功能，7 月首批 APK 不保证包含。旧包没有相应设置时，不要按新源码界面寻找。

## 常见问题

**手机连上了，游戏却没有声音？**

手机只发送开关状态。检查电脑麦克风、游戏的 PTT 按键和麦哨的按键是否一致，再检查辅助功能 / 管理员权限。麦哨显示 OPEN 不等于目标软件已接收按键。

**电脑摄像头打开失败？**

先检查系统摄像头权限、设备选择和是否被其他软件占用，再保存报错文字反馈。sidecar 自检通过不代表摄像头与 GUI 已通过验收。

**手机黑屏后还能识别吗？**

应用内「关闭屏幕」是黑色保护层，会降低亮度并减少界面刷新；不是按电源键锁屏。系统锁屏或把 app 放到后台可能暂停相机。

**一定要开算法更新吗？**

不需要。首次试用建议关闭「检查更新」，使用包内算法。当前更新链路尚未配置默认强制验签公钥。

仍有问题时，按[反馈说明](../CONTRIBUTING.md)提交设备、版本和复现步骤。
