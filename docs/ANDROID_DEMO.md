# Android Demo 说明

## 1. 目标

这个 Android demo 用于在手机上验证 VocaGate 的第一版视觉麦控链路：

```text
手机摄像头
  -> CameraX 预览和帧分析
  -> ML Kit 人脸和嘴部轮廓
  -> 嘴部开合比例和运动节奏
  -> speak_score
  -> CLOSED / PRE_OPEN / OPEN / HOLD / COOLDOWN / SUSPEND
  -> 屏幕显示模拟麦克风状态
```

它目前只显示模拟结果，不读取真实麦克风，也不输出虚拟麦克风。

## 2. 当前功能

- 使用前置摄像头，失败时回退到后置摄像头；
- 显示实时相机画面；
- 绘制嘴部轮廓点；
- 显示当前 `State`；
- 显示 `Gate: OPEN / BLOCKED`；
- 显示 `Score`、`Mouth`、`Rhythm`、`FPS`；
- 支持“开始录音测试 / 停止录音测试”；
- 录音测试会同时生成 `full.wav` 和 `gated.wav`；
- `full.wav` 是全程原始录音；
- `gated.wav` 和 `full.wav` 时间线等长，未开麦区域写入静音；
- 每次重新开始录音测试时会清空旧录音，只保留最新一次测试的文件；
- 停止测试后显示初版“麦哨值”、抑制比例、开麦比例和状态抖动，并可进入“查看录音文件”页面直接播放对比；
- 支持基础滑杆调参：灵敏度、响应速度、闭麦保持，默认收起，点击“显示设置”后展开；
- 支持“关闭屏幕”保护层：界面变黑并降低亮度，但相机分析、录音测试和电脑端按键控制继续运行，点击黑屏区域恢复显示；
- 支持通过 USB ADB reverse 或局域网 Wi-Fi 连接电脑端 companion，把 `PRE_OPEN / OPEN / BLOCKED` 映射成电脑上的按键保持；
- 人脸丢失或嘴部轮廓无效时进入 `SUSPEND`；
- 使用 bundled ML Kit face detection 依赖，模型随 app 打包，不依赖首次运行时下载。


## 4. 在手机上运行

推荐方式：

1. 安装 Android Studio。
2. 打开项目根目录 `VocaGate/`。
3. 等待 Gradle sync 完成。
4. 手机开启开发者选项和 USB 调试。
5. 在 Android Studio 中选择手机设备。
6. 点击 Run。
7. 首次启动时授权相机权限。

命令行方式：

```bash
gradle :app:installDebug
```

如果需要命令行安装，先确保本机有 Android SDK、Gradle、ADB，并设置好对应 PATH。

## 5. 手机测试动作

第一轮建议按下面顺序测试：

```text
正常说话
沉默看屏幕
张嘴不说话
哈欠
大笑
喝水
低头看手机
转头说话
强屏幕反光
暗光
```

观察重点：

- `OPEN` 是否能跟上开始说话；
- 不说话时是否频繁误开；
- 哈欠和喝水是否进入 `SUSPEND` 或保持 `BLOCKED`；
- 转头和低光时状态是否过于敏感；
- FPS 是否稳定。

## 6. 录音测试

点击：

```text
开始录音测试
```

测试过程中 app 会写两条 WAV：

```text
full.wav
gated.wav
```

点击：

```text
停止录音测试
```

屏幕会显示：

```text
麦哨值
抑制百分比
开麦百分比
状态抖动次数/分钟
```

点击：

```text
查看录音文件
```

会进入二级页面。这个页面可以直接播放：

```text
全程录音 full.wav
开麦后录音 gated.wav
```

两条录音来自同一次测试，并且时间线等长，所以可以先听 `full.wav` 了解真实环境声，再听 `gated.wav` 判断门控后保留了多少说话内容、过滤了多少非说话声音。

录音文件保存在 app 私有目录的 `vocagate-tests/latest/` 下。每次点击“开始录音测试”都会清空旧的 `latest/` 目录，因此手机上只保留最新一次测试的两条录音。

第一版“麦哨值”是调参参考值，不是最终产品评分。它主要根据：

```text
全程音频能量
门控后音频能量
开麦占比
OPEN/BLOCKED 切换频率
```

来估计这次测试里麦哨抑制噪声和保持稳定的效果。

建议测试方式：

1. 开始录音测试；
2. 沉默 5 秒；
3. 正常说话 10 秒；
4. 喝水或哈欠 5 秒；
5. 再正常说话 10 秒；
6. 停止录音测试；
7. 点击“查看录音文件”，直接播放对比 `full.wav` 和 `gated.wav`。

## 7. 基础设置

当前有三条滑杆：

| 设置 | 作用 |
|---|---|
| 灵敏度 | 越高越容易开麦，误开风险也会升高 |
| 响应速度 | 越高越快进入 OPEN，吞字风险更低，但更容易误触发 |
| 闭麦保持 | 越高越不容易切掉句尾，但停止说话后会保持更久 |

首页默认隐藏这些调参控件，让测试状态更干净。需要调参时点击：

```text
显示设置
```

滑杆会在首页展开，可以一边说话一边观察状态变化。调完后再次点击：

```text
隐藏设置
```

即可收起。

建议第一轮只调这三项，不直接改高级权重。

## 8. 屏幕保护层

游戏或语音测试时，如果不想让手机画面持续发光或干扰视线，可以点击首页：

```text
关闭屏幕
```

进入后 app 会显示全黑覆盖层，并把当前 Activity 亮度降到很低。它不会调用系统锁屏，也不会停止 CameraX 分析、录音测试或 PC 端 `OPEN / BLOCKED` 发送。

恢复显示时，点击黑屏任意位置即可。离开 app 或切到后台时也会自动恢复亮度。

## 9. 已知限制

- 嘴部轮廓绘制坐标目前是开发版近似映射，前置摄像头已做镜像处理，但不同机型上可能存在偏移；
- 还没有 CSV 日志；
- 还没有完整独立设置页，当前是首页内可展开的三条基础滑杆；
- 还没有音频环形缓冲；
- 还没有真实麦克风门控；
- USB 闭环需要 USB 调试和 `adb reverse`；Wi-Fi 闭环需要手机和电脑在同一个可互通局域网；
- “关闭屏幕”是 app 内黑屏保护层，不是系统级关闭物理屏幕；这样可以避免 Android 锁屏后暂停相机；
- ML Kit Face Detection 不是完整 Face Mesh，嘴部点位比 MediaPipe Face Mesh 少，但足够做第一轮手机验证。
