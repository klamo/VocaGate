# 麦哨 VocaGate 0.2.0 · 首次开源预览

> 首次开源预览（非稳定版），供早期试用。安装包来自既有构建，尚未完成 GUI、摄像头和真实按键链路验收。下载以 GitHub Release 实际附件为准。

自由麦太吵，按键麦太累。麦哨尝试用摄像头观察嘴部运动，在你说话时自动按住电脑上的按键说话键。

本次开放自有源代码并提供首批 Android / Windows 安装包，欢迎小范围试用和反馈。不包含账号、支付、自动续费或完整统计平台。

## 下载哪个文件？

| 平台 | 附件 | 安装 |
| --- | --- | --- |
| Android 6.0+ | `VocaGate-0.2.0-android.apk` | 在手机打开 APK 安装 |
| Windows x64 | `VocaGate-0.2.0-windows-x64.zip` | 完整解压，运行其中的 `VocaGate.exe` |

**macOS 暂不发布。** 本轮 sidecar 健康检查在当前环境中失败，原 DMG 也存在签名完整性问题。修复后的应用 ZIP 仅保留为本地候选，等待进一步验证。Windows 是绿色 ZIP，不是 EXE 安装器。

桌面包内置 Java、MediaPipe sidecar 和模型。USB 模式仍依赖电脑已有 ADB 和手机 USB 调试授权；Wi-Fi 可手动填写 IP、端口与六位码，不需要 USB 授权。

## 二进制来源与源码区别

- Android 和 Windows 使用 2026 年 7 月的原安装包，字节内容没有修改，保留原 SHA-256。
- macOS 使用 7 月的本地 app-image 副本，重新生成临时签名后打成 ZIP；没有重新编译 Java 或 sidecar。原 APK、DMG、Windows ZIP 全部保留。
- APK 内嵌 Git revision 为 `052408b68ca6824c55c62f70a3e3f48dedfb1bc2`，但它不证明当时工作区无未提交改动。原构建没有可核对的完整源码指纹，不能声称这些包精确对应 `6ce07c3` 或本次发布标签。
- 当前 `main` 包含后来提交的 Android 音频辅助、连续讲话保持等改动。旧包是否包含各项能力需逐项核实，不能以首页功能表代替包内验证。
- 发布标签只固定本次源码和说明。附件 `ARTIFACT_PROVENANCE.json` 记录所附安装包的来源、哈希和验证状态。

## 首次使用

1. 选择电脑摄像头，或将安卓手机连接到电脑端。
2. 在麦哨和目标游戏 / 语音软件中设置相同的按键说话键。
3. 开始识别，先验证说话、沉默、遮挡和断连时按键的按下 / 释放。

手机负责识别时不会成为电脑麦克风，目标软件仍使用电脑配置的音频输入。详细步骤见[快速上手](QUICK_START.md)。

## 已知限制

- 桌面包没有发行者签名和公证。macOS 临时签名仅修复资源完整性，系统仍可能显示首次打开提示。
- Mac 需要摄像头与辅助功能权限；Windows 可能需要与目标软件匹配运行权限。部分游戏或反作弊系统不接受模拟按键。
- Android debug 版需卸载后才能安装 release 版，原设置和测试录音会被清除。已有同签名 release 版不要随意卸载；今后升级须沿用原 release 密钥并提高 versionCode。
- 当前源码启动流程仍要求麦克风权限；音频辅助并不能仅凭声音触发开麦。
- 自动发现、扫码配对、内置隔离 ADB 尚未实现。
- 更新检查和旧统计开关仍在。默认调用尚未强制配置签名验证公钥，首次试用建议关闭算法更新。

## 校验下载

与实际附件同时发布 `SHA256SUMS.txt`，例如在 macOS 下载目录执行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Windows 可以用 PowerShell `Get-FileHash -Algorithm SHA256 <文件路径>`，与清单逐项对照。
